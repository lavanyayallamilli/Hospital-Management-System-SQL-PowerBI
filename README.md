# Hospital Management System | SQL + Power BI

## Project Overview
This project is a Hospital Management System developed using SQL and Power BI.

The system manages:
- Patient Records
- Doctor Information
- Appointments
- Billing Details
- Department Information

## Technologies Used
- SQL
- Power BI
- Excel

## Database Tables
- Patients
- Doctors
- Appointments
- Billing
- Departments

## Features
- Patient Management
- Doctor Management
- Appointment Scheduling
- Billing Analysis
- Dashboard Reporting

## Power BI Visualizations
- Patients by Gender
- Patients by City
- Billing Status Analysis
- Appointment Status Analysis

- Hospital_Management.sql
